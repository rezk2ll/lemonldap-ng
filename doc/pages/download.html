Getting sources from SVN repository

Anonymous access

Sources are currently available on OW2. You can simply checkout sources with the following command: 

svn checkout svn://svn.forge.objectweb.org/svnroot/lemonldap

Developer access

LemonLDAP::NG developer must have a account on OW2 platform, and could authenticate themselves via SSH 2 by using the following one: 

svn checkout svn+ssh://developername@svn.forge.objectweb.org/svnroot/lemonldap
