Second factors

Two-factor authentication (also known as 2FA) is a type (subset) of multi-factor authentication. It is a method of confirming a user's claimed identity by utilizing a combination of two different factors:

  1. something they know (password,…),
  2. something they have (U2F key, smartphone,…), or something they are (biometrics).

Since 2.0, LLNG provides some second factor plugins that can be used to complement auth module for 2FA:

  • U2F tokens
  • TOTP (to use with FreeOTP, ||https://en.wikipedia.org/wiki/Google_Authenticator|Google-Authenticator]],…)
  • U2F-or-TOTP (enable both U2F and TOTP)
  • Yubikey tokens
  • REST (to call an external command)
  • External 2F (Remote REST app)

Developer corner

To develop a new 2FA plugin, read the Lemonldap::NG::Portal::Main::SecondFactor (3pm) manpage. Your 2F module must be a Perl class named Lemonldap::NG::Portal::2F::<custom_name> To enable it, you can set available2f key in your lemonldap-ng.ini file: 

[portal]
available2F = U2F,TOTP,<custom_name>
