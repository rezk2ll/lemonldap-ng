Translations

Translators that want to help us are welcome !

Portal translation

2 kind of files may be translated:

  • HTML templates: in <lang> tags, add your translation, they will be automaticaly used
  • Portal messages: all messages are grouped in lemonldap-ng/lib/Lemonldap/NG/Portal/_i18n.pm. You just have to create error_zz and msg_zz subroutines (where zz is your international code, example: “fr” for France) by copying error_en and msg_en. Note that you have to use UTF-8 characters

Manager translation

2 kind of files may be translated:

  • Manager interface: all messages are grouped in lemonldap-ng-manager/lib/Lemonldap/NG/Manager/_i18n.pm. Copy en subroutine to zz (where zz is your international code, example: “fr” for France) then translate messages. Note that you have to use UTF-8 characters
  • Documentation: use OmegaT to translate offline documentation and configure it:
    • Project = [path/to/trunk/build/lemonldap-ng]/omegat.files/zz (where zz is your international code, example: “fr” for France)
    • Source directory = [path/to/trunk/build/lemonldap-ng]/doc/
    • Destination directory = [path/to/trunk/build/lemonldap-ng]/po-doc/zz (where zz is your international code, example: “fr” for France)
    • translation memory directory = [path/to/trunk/build/lemonldap-ng]/omegat.files/zz/tm/
    • Glossary directory = [path/to/trunk/build/lemonldap-ng]/omegat.files/zz/glossary/

Update translations

To update translations, ask to lemonldap-ng-dev@ow2.org to update your files. If you want to become member of LL::NG team ask to lemonldap-ng-dev@ow2.org.

When you commit OmegaT files in svn repository, don't push backup files.
