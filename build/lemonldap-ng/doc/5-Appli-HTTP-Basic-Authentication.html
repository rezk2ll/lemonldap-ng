Extract from the Wikipedia article:

In the context of an HTTP transaction, the basic access authentication is a method designed to allow a web browser, or other client program, to provide credentials â€“ in the form of a user name and password â€“ when making a request.

Before transmission, the username and password are encoded as a sequence of base-64 characters. For example, the user name Aladdin and password open sesame would be combined as Aladdin:open sesame â€“ which is equivalent to QWxhZGRpbjpvcGVuIHNlc2FtZQ== when encoded in Base64. Little effort is required to translate the encoded string back into the user name and password, and many popular security tools will decode the strings "on the fly".

Configuration in LemonLDAP::NG



The Basic Authentication relies on a specific HTTP header, as described above. So you have just to declare this header for the virtual host in LemonLDAP::NG Manager:

Authorization => "Basic ".encode_base64("login:password")


The problem is to have correct values in login and password.

We suppose for example that the login is the attribute "uid" and the password is the password used to authenticate on LemonLDAP::NG portal. To store this password into session, you first have to modify the /var/lib/lemonldap-ng/portal/index.pl:

# Remove comment to store password in session (use with caution)
        storePassword      => 1,


Warning: this will store the password in cleartext, so if an attacker achieve to read the session on the server, he can read the password.

With the storePassword parameter, the password is available in LemonLDAP::NG in $_password.

So to configure basic authentication:

Authorization => "Basic ".encode_base64("$uid:$_password")
