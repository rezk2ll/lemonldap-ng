Presentation

You can store sessions in LDAP directory. You need to install Apache::Session::LDAP to use this functionnality.

This will use a branch of your directory to manage Apache session.

Configuration

Parameters are:
  • ldapServer: URI of the server
  • ldapConfBase: DN of session branch
  • ldapBindDN
  • ldapBindPassword
