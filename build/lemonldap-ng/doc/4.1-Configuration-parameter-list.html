Documentation applicable for LemonLDAP::NG >= 1.0

Configuration

  • Order: configuration number/order (the highest number is the one applied)
  • Name: friendly name of the configuration
  • Createtimestamp: date of creation
  • Modifytimestamp: date of last modification
  • Applytimestamp: date of last application

General Parameters

  • Authentication Parameters
    • Authentication Type (ldap|ssl|cas|apache|saml2): how users are authenticated
  • User base Parameters
    • User base Type (ldap|dbi|saml2): how access to stored user's information
  • Portal parameters
    • Portal URL: URL of the authentication portal
    • Portal Theme: name or path to the theme/skin
    • keepExistingSession(0|1): do not force users to relogin on portal page

    • Secured cookie (0|1): use secures cookie (only sent over SSL connections)
