# Contributing to LemonLDAP::NG

## Submit an issue

You need ot have an account on OW2 forge: https://gitlab.ow2.org/

Then go https://gitlab.ow2.org/lemonldap-ng/lemonldap-ng

See also https://lemonldap-ng.org/documentation/latest/bugreport.html

## Report a security issue

Send a mail to lemonldap-ng-security@ow2.org

See also https://lemonldap-ng.org/.well-known/security.txt

## Tranlations

* Software : https://app.transifex.com/lemonldapng/lemonldapng/

* Dcumentation : since 2.0, LL::NG community supports only english doc

## Contributing code

You can open a Merge Request on OW2 gitlab: https://gitlab.ow2.org/lemonldap-ng/lemonldap-ng

See also https://lemonldap-ng.org/documentation/latest/contribute.html

### AI usage

Usage of AI is allowed to help developers to contribute to the source code of LemonLDAP::NG, with these restrictions:

* Code generated by AI must be reviewed and tested by a human
* A Merge Request done by AI is in draft status until this review and tests have been done
* AI must be listed as coauthor of the commit (for example: `Co-Authored-By: Claude <noreply@anthropic.com>`)
