Présentation

BrowserID est également connu sous le nom de « Mozilla Persona ». C'est un protocole d'authentification unique (Single Sign On) similaire à OpenID, mais basé sur l'adresse emailde l'utilisateur au lieu d'une URL. Il y a bien sur d'autres différences.

Voir la description complète du protocole ici : https://developer.mozilla.org/en-US/docs/Mozilla/Persona

Configuration

Dans le manager, aller dans Paramètres généraux > Modules d'authentification et choisir BrowserID pour l'authentification.

On peut ensuite choisir n'importe quel autre module de gestion des utilisateurs et des mots-de-passe mais pour déléguer totalement l'authentification à BrowserID, choisir None pour la gestion des utilisateurs et des mots de passe.

Ensuite, aller dans les paramètres BrowserID:

  • Niveau d'authentification : niveau d'authentification accordé à ce module.
  • Authentification automatique : mettre à 1 pour utiliser la connexion automatique. Ce mode n'est pas compatible avec de nombreux navigateurs qui bloquent les pop-ups.
  • URL de vérification : URL utilisée pour vérifier l'assertion BrowserID. Laisser vide pour utiliser l'URL de vérification par défaut de Mozilla (https://verifier.login.persona.org/verify)
  • Nom du site : Nom qui sera affiché dans la fenêtre d'authentification BrowserID
  • Logo du site : Logo qui sera affiché dans la fenêtre d'authentification BrowserID. Il faut fournir une URI complète (par exemple /skins/common/lemonldap-ng_square.png) et utiliser HTTPS pour le portail
  • Couleur d'arrière plan : Couleur d'arrière plan affichée dans la fenêtre d'authentification BrowserID
