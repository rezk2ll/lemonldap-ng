Présentation

LL::NG utilise Authen::Radius de Perl comme simple backend d'authentification.

Actuellement, ce module traite simplement une requête d'authentification Radius et n'a été testé que sur un serveur FreeRadius.

Configuration

Installer Authen::Radius

Il faut installer le module Perl correspondant.

Pour CentOS/RHEL : 

yum install perl-Authen-Radius

Pour Debian/Ubuntu, installer la librairie via la commande apt-get 

apt-get install libauthen-radius-perl

Configuration de LemonLDAP::NG

Dans le manager, aller dans Paramètres généraux > Modules d'authentification et choisir Radius pour l'authentification.

Vous pouvez ensuite choisir vos modules d'utilisateurs et de mots-de-passe.

Ensuite, aller dans les paramètres Radius:

  • Niveau d'authentification : niveau d'authentification pour Radius
  • Secret partagé : la phrase de passe à utiliser pour se connecter au serveur Radius
  • Nom d'hôte du serveur : le nom d'hôte ou l'adresse IP du serveur Radius
