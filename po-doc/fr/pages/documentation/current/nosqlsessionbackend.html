Module de stockage des sessions Redis

Apache::Session::Redis est le module de stockage des sessions en réseau le plus rapide

Mise en marche

Installez et lancer un serveur Redis. Installez le module Perl Apache::Session::Redis.

Dans le manager : indiquez Apache::Session::Redis dans Paramètres généraux » Sessions » Stockage des sessions » Module Apache::Session et ajoutez les paramètres suivant (sensibles à la casse):

Paramètres exigés
Nom Commentaire Exemple
server Serveur Redis 127.0.0.1:6379

Sécurité

Restreignez l'accès réseau au serveur Redis. Pour les serveurs distants, vous pouvez utiliser le module SOAP d'accès aux sessions en complément pour augmenter la sécurité de ces serveurs qui accèdent aux sessions au travers d'un réseau non sûr
