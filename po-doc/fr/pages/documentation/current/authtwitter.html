Présentation

Twitter est un serveur de microblog célèbre. Twitter utilise le protocole OAuth pour autoriser les applications à réutiliser son propre processus d'authentification (ce qui signifie que si vous êtes connecté à Twitter, d'autres applications peuvent agréer Twitter et vous laisser entrer).

Vous devez installer une version récente (>3) du paquet Net::Twitter.

Vous devez enregistrer votre nouvelle application dans Twitter pour obtenir la clef de l'API et son secret. Reportez-vous à la FAQ Twitter pour en savoir plus.

Configuration

Dans le manager, allez dans Paramètres generaux > Modules d'authentification et choisissez Twitter comme module d'authentication.

Vous pouvez ensuite choisir vos modules d'utilisateurs et de mots-de-passe.

Allez ensuite dans Paramètres Twitter :

  • Niveau d'authentification : niveau d'authentification accordé à ce module.
  • Clef d'API: clef d'API donnée par Twitter
  • Secret d'API: secret d'API donné par Twitter
  • Nom d'application (optionel) : nom de l'application (visible dans Twitter)
