Captcha

Présentation

Captcha est un mécanisme de sécurité utilisé pour éviter des des robots ne soumettent des formulaires.

Les captchas sont disponibles sur les formulaires suivants :

  • formulaire de connexion : où les utilisateurs entrent leurs login/mot-de-passe
  • Formulaire de réinitialisation de mot-de-passe par courriel
  • Formulaire d'enregistrement : où les utilisateurs entrent les informations nécessaires à la création de compte
We use the Perl module GD::SecurityImage to generate images, you need to install it if you enable Captcha feature.

Configuration

Aller à Paramètres généraux » Portail » Captcha :

  • Activation dans le formulaire de connexion : mettre à 1 pour activer le captcha dans ce formulaire
  • Activation dans le formulaire de réinitialisation de mot-de-passe : mettre à 1 pour activer le captcha dans ce formulaire
  • Activation dans le formulaire d'enregistrement : mettre à 1 pour activer le captcha dans ce formulaire
  • Taille : longueur du captcha
