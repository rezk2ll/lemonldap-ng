Configurer LemonLDAP::NG pour utiliser le mécanisme mandataire SOAP

LL::NG utilise 2 bases de données interne pour stocker ses configuration et sessions. It can be configured to use SOAP instead of direct access to those databases (for remote servers).

Ce mécanisme peut être utilisé pour sécuriser l'accès des serveurs distants qui traversent des réseaux non sécurisés pour accéder aux bases de données de LL::NG.

Since version 2.0, same services are available by REST.

Utiliser SOAP pour la configuration Lemonldap::NG

Étapes :

  • Choisir et configurer le système principal de stockage de la configuration
  • Suivre la documentation backend de configuration SOAP
  • Redémarrer tous les serveurs Apache distants

Utiliser SOAP pour les sessions Lemonldap::NG

Étapes :

  • Choisir et configurer le système principal de stockage des sessions
  • Suivre la documentation backend de sessions SOAP
