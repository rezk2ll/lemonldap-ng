Fonctionnalités principales

Contrôle d'accès complet

LL::NG est un système d'authentification web unique (WebSSO), mais contrairement à d'autres, il peut gérer les droits d'accès en utilisant des expressions rationnelles sur les URL demandées.

Facile à personnaliser

LL::NG a été conçu en utilisant l'architecture logicielle Modèle–Vue–Controlleur, ainsi vous avez juste à modifier les fichiers HTML/CSS pour personnaliser son portail.

Facile à intégrer

Integrer des applications dans LL::NG est facile car leur dialogue est basé sur des en-têtes HTTP personnalisables.

Unifier les authentifications (fédération)

LL::NG peut aisément dialoguer avec d'autres systèmes d'authentification en utilisant SAML, OpenID, CAS. il peut être le pivot d'une architecture hétérogène. Its SOAP API can also be used to dialog directly with your custom applications.

Sessions

Explorateur de sessions

Le gestionnaire de LL::NG dispose d'un explorateur de sessions qui peut être utilisé pour parcourir sessions ouvertes :

  • par utilisateurs
  • par adresses IP
  • par date
  • par double IP (sessions ouvertes par le même utilisateur sur plusieurs machines)

Il peut être utilisé pour effacer une session

Resctriction d'ouverture de session

Par défaut, un utilisateur peut ouvrir plusieurs sessions. LL::NG peut restreindre cet usage :

  • N'autoriser qu'une session par utilisateur
  • N'autoriser qu'une adresse IP par utilisateur
  • N'autoriser qu'une session par adresse IP

Ces capacités peuvent être utilisées simultanément ou séparemment.

Double cookie

LL::NG peut être configuré pour fournir 2 cookies:

  • one secured (SSL only) for sensitive applications
  • un non-sécurisé pour les autres applications

Ainsi, si le cookie http cookie est volé, les applications sensibles restent protégées.

Notifications

LL::NG peut être utilisé pour présenter des messages aux utilisateurs. Ceci peut être utilisé pour notifier des changements de droits,... Consultez la page notifications pour plus d'information.
