Présentation

LL::NG peut transferer (en utilisant SOAP) les éléments d'authentification à un autre portail LL::NG, comme un proxy.

La différence avec l'authentification "Remote" est que le client n'est jamais redirigé vers le portail LL::NG principal. Cette configuration est utilisable l'on soujaite exposer un portail SSO interne à une autre réseau (DMZ).

Configuration

Portail externe

Dans le manager, aller dans Paramètres généraux > Modules d'authentification et choisir Proxy pour les modules authentification et utilisateurs.

Ensuite, aller dans les paramètres Proxy :

  • URL du portail : URL du portail interne
  • Nom du cookie (optionnel) : nom du cookie du portail interne s'il est différent de celui du portail externe
  • Point terminal des sessions SOAP (optionnel): URL du service SOAP si elle n'est pas basée sur celle du portail interne avec le suffixe index.pl/sessions

Portail interne

Ce portail doit être configuré pour accepter les requêtes d'authentification SOAP. Voir la documentation du backend de sessions SOAP.
