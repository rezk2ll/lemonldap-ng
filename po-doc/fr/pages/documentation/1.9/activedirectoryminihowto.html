Utiliser Lemonldap::NG avec Active-Directory

Authentification par nom-de-compte/mot-de-passe

Pour utiliser Active Directory comme serveur LDAP, vous devez effectuer quelques modifications dans le manager :

  • Utiliser “Active Directory” comme systèmes d'authentification, de gestion des utilisateurs et des mots-de-passe,
  • Exporter sAMAccountName dans la liste des variables exportées
  • Changer l'attribut utilisateur à stocker dans les journaux d'Apache (“Paramètres généraux » Journaux » REMOTE_USER”) : utiliser la variable ci-dessus

Authentification avec Kerberos

  • Choisir “Apache” comme module d'authentification (“Paramètres généraux » Modules d'authentification » Module d'authentification”)
  • Configurer le serveur Apache qui héberge le portail utilisant le module d'authentification Kerberos d'Apache
