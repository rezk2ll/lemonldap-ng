Comment changer le backend de configuration

LemonLDAP::NG fournit un script pour changer aisément de backend de configuration en conservant l'historique. Il se traouve dans le répertoire des utilitaires LemonLDAP::NG (convertConfig).

Fonctionnement

L'utilitaire convertConfig lit 2 fichiers de configuration LL::NG (lemonldap-ng.ini) :

  • Current : pour extraire tout l'historique de la configuration
  • New : pour écrire l'historique de la configuration

On y va

  • Preparer le nouveau lemonldap-ng.ini file
  • Configure your new backend (create SQL database,…)
  • Lancer ceci :
convertConfig --current=/etc/lemonldap-ng/lemonldap-ng.ini --new=/new/lemonldap-ng.ini
  • Installer le nouveau fichier lemonldap-ng.ini à la place de l'ancien dans tous les serveurs LL::NG
  • Redémarrer tous vos serveurs Apache
