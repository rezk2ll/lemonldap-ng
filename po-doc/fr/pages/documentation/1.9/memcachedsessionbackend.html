Backend de session Memcached

Memcached peut être utilisé avec LL::NG, mais quelques fonctionnalités ne marcheront pas car Memcached ne fournit pas de dispositif de parcours des données :

  • Expiration des sessions : les sessions n'expirent jamais (du côté serveur)
  • L'explorateur de session ne fonctionne pas
  • Les restrictions de session ne fonctionnent pas

Pour maintenir un niveau de performance tel celui de Memcached et préserver les fonctionnalités de LL::NG, on peut remplacer Memcached par Redis en utilisant le backend de sessions NoSQL.

Mise en marche

Installer et lancer un serveur Memcached.

Dans le manager : indiquez Apache::Session::Memcached dans Paramètres généraux » Sessions » Stockage des sessions » Module Apache::Session et ajoutez les paramètres suivant (sensibles à la casse) :

Paramètres exigés
Nom Commentaire Exemple
Servers Serveurs memcached 10.0.0.1:20000 10.0.0.2:20000

Voir Apache::Session::Memcached pour les paramètres optionnels.
