RoundCube

Présentation

Le webmail RoundCube est un client IMAP web multilingue une interface riche type application. Il fournit toutes les fonctionnalités attendues d'un client email, y compris support MIME, carnet d'adresses, manipulation des dossiers, recherche de messages et correcteur d'orthographe.

Configuration

LemonLDAP::NG

  • Ajouter un nouvel hôte virtuel webmail.domain.tld
  • Ajouter une nouvelle règle :
"^/\?_task\=logout" -> "logout_app https://auth.domain.tld"
  • Dans les en-têtes HTTP, ajouter Auth-User ($mail) and Auth-Pw ($_password).

Pour savoir comment transmettre les mots de passe à RoundCube, voir comment stocker le mot de passe dans la session

  • Configurer l'hôte virtuel Apache ou Nginx

RoundCube

  • installer le plugin http_authentication
  • Le modifier pour remplacer PHP_AUTH_* par HTTP_AUTH_*
  • activer le plugin http_authentication dans main.inc.php :
$rcmail_config['plugins'] = array('http_authentication');
