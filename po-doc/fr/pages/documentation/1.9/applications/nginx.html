Nginx

Nginx est pleinement supporté par LemonLDAP::NG depuis la version 1.9.

Présentation

Nginx est un serveur web particulièrement performant. Il peut être utilisé pour héberger le portail ou le manager au travers de son support FastCGI et peut être utilisé pour protéger des applications en utilisant le module auth_request (qui dialogue avec un serveur d'autorisations FastCGI). Voir les pages d'installation pour apprendre à l'installer et l'utiliser.
