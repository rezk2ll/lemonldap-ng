Support FastCGI

Le manager répond désormais nativement au protocole FastCGI. Le portail suivra d'ici la version 2.0

Le portail LL::NG peut être utilisé dans un système FastCGI très facilement. Il suffit de charger le support FastCGI de <a3>LL::NG</a3> et d'écrire une boucle dans la <a4>CGI</a4>. Exemple avec le portail : 

#!/usr/bin/perl
use Lemonldap::NG::Common::CGI qw(fastcgi);
use Lemonldap::NG::Portal::SharedConf;
# ...

LMAUTH: while ( my $portal = Lemonldap::NG::Portal::SharedConf->new({}) ) {
    # ...
}

Etapes clefs :

  • Charger “Lemonldap::NG::Common::CGI qw(fastcgi)“ avant toute autre librairie <a2>LL::NG</a2>
  • insérer une boucle autour de l'affichage HTML, démarrant avec la création de l'objet (→new)
  • insérer le label “LMAUTH” en tête de la boucle

Un exemple est disponible dans l'arborescence des sources : lemonldap-ng-portal/example/index.fcgi
