Null

Authentification Utilisateurs Mot-de-passe
✔ ✔ ✔

Présentation

Le backend Null de LL::NG est un backend transparent :

  • Authentification : créé une session sans demander quoi que ce soit (mais enregistre l'adresse IP cliente et la date de création)
  • Utilisateurs : ne collecte aucune donnée (mais il est possible d'enregistrer des variables d'environement dans la session)
  • Mots-de-passe : ne change aucun mot-de-passe

Le backend Null peut être utilisé pour sauter des étapes du processus d'authentication.

Configuration

Dans le manager, aller dans Paramètres généraux > Modules d'authentification et choisir <a2>Null</a2>) pour les modules authentification, utilisateurs et/ou mots-de-passe.

Aller ensuite dans les paramètres Null:

  • Niveau d'authentification : niveau d'authentification accordé à ce module.
